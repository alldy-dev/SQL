# SQL Course - Baraa

This repository contains my exercises and notes from the SQL course taught by Baraa.  
The course is available on YouTube at: [SQL Course - Baraa](https://www.youtube.com/watch?v=SSKVgrwhzus&t=66221s)

## Course Chapters
1. Introduction  
2. Query Data (SELECT)  
3. Data Definition (DDL)  
4. Data Manipulation (DML)  
5. Filtering Data  
6. Combining Data

8. Aggregation & Analytical Functions

10. Performance Optimization
